# Support

MotionPR is maintained in the open by one person. Here is where each kind of question gets the
fastest answer.

| You want to…                      | Go to                                                                                                                                                |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Get started, or look something up | The [documentation](https://erenthedeveloper0.github.io/motionpr/docs/) (searchable), or [docs/](docs/) on GitHub                                    |
| Fix a failing capture             | `npx motionpr doctor`, then [Troubleshooting](docs/advanced/troubleshooting.md)                                                                      |
| Report a bug                      | [Open an issue](https://github.com/erenthedeveloper0/motionpr/issues/new/choose) with a minimal reproduction and the output of `npx motionpr doctor` |
| Ask for a feature                 | [Open a feature request](https://github.com/erenthedeveloper0/motionpr/issues/new/choose); check the [roadmap](ROADMAP.md) first                     |
| Report a vulnerability            | Privately, never in an issue: [SECURITY.md](SECURITY.md)                                                                                             |
| Contribute                        | [CONTRIBUTING.md](CONTRIBUTING.md)                                                                                                                   |

## Before you open an issue

1. Run `npx motionpr doctor` and fix what it reports.
2. Search the [existing issues](https://github.com/erenthedeveloper0/motionpr/issues).
3. Reduce the problem: one scenario, one page, one animation. A scenario and a small HTML file
   that reproduce it are worth more than a description of a large app.

## What to expect

MotionPR is an **alpha**. Bugs with a reproduction are fixed first; questions are answered as time
allows. There is no paid support and no service level.
